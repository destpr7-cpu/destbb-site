# Подключение админки dest.bb

Админка открывается по адресу `/admin.html`. Оригинальную папку сайта не менять — работаем с `destbb-site-main (рабочая копия)`.

## 1. Создать хранилище Supabase

1. Создай проект Supabase и дождись завершения настройки.
2. Открой **SQL Editor**, вставь весь файл `admin-setup.sql` и выполни его. Он создаст каталог, архив заказов, начальные 5 товаров и безопасное списание остатков при подтверждении оплаты.
3. В **Storage** создай bucket с именем `product-images` и включи **Public bucket**. Ограничь загрузку изображениями PNG/JPG/WEBP и размером до 3 МБ.

В начальных товарах остаток равен нулю. Перед продажами внеси фактическое наличие по размерам. Когда добавишь товар, задай ему уникальный ID латиницей, например `scarf-black`.

## 2. Добавить секреты в Vercel

В проекте Vercel открой **Settings → Environment Variables** и добавь для Production:

- `SUPABASE_URL` — Project URL из Supabase API settings.
- `SUPABASE_SERVICE_ROLE_KEY` — секретный service role key из Supabase API settings.
- `ADMIN_PASSWORD` — придуманный пароль админки.
- `ADMIN_SESSION_SECRET` — длинная случайная строка, минимум 32 символа.

Секретный service role key нельзя добавлять в HTML, GitHub или отправлять в чат. После сохранения переменных заново разверни сайт на Vercel.

## 3. Пользоваться

Открой `https://destbb.com/admin.html` и войди с `ADMIN_PASSWORD`.

- В **Товарах** можно создать товар, загрузить фотографии, поменять цену и скидку, наличие по размерам, порядок карточки и видимость.
- Переключатель **Предзаказ** меняет кнопку товара на сайте.
- Во вкладке **Заказы** открой заказ и отметь его оплаченным после проверки платежа. Остаток спишется один раз; предзаказы не списываются из складского наличия.
- Скрытые товары остаются в базе и истории заказов. Их можно снова показать, включив флажок видимости.

## Что уже связано в коде

- Главная страница и новые ссылки `/products/<id>` читают каталог из `/api/catalog`.
- Сервер оформления заказа заново берёт цену и скидку из каталога, а не доверяет цене браузера.
- Заказы после отправки в Telegram сохраняются для админки.
- Загрузка фотографий проходит через серверный API; ключ Supabase остаётся на сервере.
